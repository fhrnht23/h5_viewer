# Правила разработки H5 Viewer

- Все комментарии и docstrings в коде писать на русском языке.
- Все сообщения Git-коммитов писать на русском языке.
- Идентификаторы, имена модулей и публичный Python API писать на английском языке.
- Все пользовательские строки проводить через систему локализации RU/EN; русский язык используется
  по умолчанию.
- Не загружать HDF5 datasets целиком без явного действия пользователя и проверки размера.
- Не изменять исходный HDF5-файл напрямую: редактирование выполняется в безопасной рабочей копии.
- Перед завершением изменения запускать pytest, ruff и mypy в объёме, соответствующем изменению.
