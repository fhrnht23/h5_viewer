# Расширения H5 Viewer

H5 Viewer обнаруживает установленные Python-пакеты через entry-point группу `h5viewer.plugins`.
Текущая версия публичного API — `1`. Ошибка одного плагина не блокирует запуск остальных или
главного приложения.

API v1 намеренно небольшой и не раскрывает `MainWindow`, h5py handles или изменяемые внутренние
модели. Плагин может:

- получить неизменяемый снимок текущего выбора;
- добавить локализованную команду в меню «Инструменты»;
- показать локализованное информационное сообщение или строку состояния.

Фабрика entry point должна вернуть объект с полями `plugin_id`, `display_name`, `api_version` и
методами `activate(host)` / `deactivate()`. Идентификатор рекомендуется задавать в reverse-domain
формате. Все UI callbacks выполняются в главном Qt-потоке, поэтому длительную работу нужно выносить
в отдельный процесс и не передавать между потоками объекты h5py.

Минимальная регистрация в `pyproject.toml`:

```toml
[project.entry-points."h5viewer.plugins"]
my-plugin = "my_plugin:create_plugin"
```

Готовый двуязычный пример находится в
[`examples/object-summary-plugin`](../examples/object-summary-plugin). Для проверки из корня
проекта:

```bash
python -m pip install -e ./examples/object-summary-plugin
h5viewer
```

После перезапуска в меню «Инструменты» появится команда «Сводка выбранного объекта…». Удаление
пакета отключает пример:

```bash
python -m pip uninstall h5viewer-object-summary
```

Несовместимая версия API, повторяющийся `plugin_id` или исключение во время активации записываются в
отчёт загрузчика. Зарегистрированные элементы нужно удалить в `deactivate()` через полученный
`PluginRegistration`.
