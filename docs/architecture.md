# Архитектура H5 Viewer

## Принципы

Приложение разделено на четыре слоя:

```text
presentation/qt  →  application  →  domain
                           ↑
              infrastructure/hdf5
```

`domain` содержит только типы значений, ошибки и протокол `HdfRepository`. Здесь ссылка HDF5
(`LinkRef`) отделена от идентичности целевого объекта. Это необходимо, потому что один объект может
иметь несколько hard links, а группы могут создавать циклы.

`application` управляет открытым документом, командами undo/redo и безопасной рабочей копией.
`DocumentSession` совместно используется обеими панелями, поэтому один файл не открывается двумя
конфликтующими write handles.

`infrastructure/hdf5` реализует доменный протокол через h5py. Ни один объект или handle h5py не
покидает инфраструктурный слой. Публичная операция открывает файл, выполняет ограниченную работу и
закрывает его. Такой подход немного дороже постоянного handle, но упрощает владение ресурсами,
переключение на рабочую копию и тестирование.

`presentation/qt` содержит Qt models/views, две панели, инспектор, темы и локализацию. Бизнес-логика
не импортирует PySide6.

## Модели Qt

`HdfTreeModel` наследует `QAbstractItemModel` и загружает членов группы страницами по 200 ссылок.
Узел хранит множество идентичностей предков; совпадение с целевым объектом новой hard link помечает
цикл и запрещает дальнейшее раскрытие.

`DatasetTableModel` хранит только одну страницу размером не более 100 × 50 элементов. Для N-D
dataset пользователь выбирает ось строк, ось столбцов и фиксированные индексы остальных измерений.
Редактирование одной ячейки преобразуется в application-команду.

Создание dataset и его расширение также оформлены обратимыми application-командами. Пользовательское
изменение размера допускает только расширение chunked dataset в пределах `maxshape`. Undo уменьшает
его до исходной формы после отмены всех более поздних команд, поэтому исходные данные не теряются.
Произвольное уменьшение потребует отдельного дискового snapshot и пока явно запрещено.

Удаление links также является обратимой командой. Для soft/external link достаточно сохранить её
метаданные. Hard link восстанавливается через другой alias того же объекта; если удаляется последняя
hard link, объект потоково копируется во временный HDF5 snapshot без загрузки payload в память.
Snapshot удаляется вместе с командой при сохранении, Discard или отбрасывании redo-ветки.

Межфайловое перемещение представлено парой команд: копированием в документ назначения и безопасным
удалением из источника. Главное окно связывает их undo/redo и соблюдает порядок восстановления
источника перед удалением копии. Физическое сохранение двух файлов остаётся неатомарным.

## Локализация

Все статические пользовательские строки проходят через `QCoreApplication.translate`. Встроенный
`DictionaryTranslator` предоставляет русский перевод без внешней зависимости от `lrelease`.
Английские source strings являются вторым языком. Выбор сохраняется через `QSettings`, русский
используется по умолчанию.

## Ограничение многопоточности

h5py сериализует обращения к HDF5 глобальной блокировкой. Небольшие ограниченные чтения пока
выполняются синхронно. Поиск, сравнение, копирование и полная проверка больших файлов должны
выполняться отдельными процессами, а не конкурентными h5py-потоками.
